PORTOFOLIO DIMAS DWI FERNANDA

ISI FOLDER
- index.html : struktur dan isi website
- style.css  : desain, tata letak, dan animasi

CARA MENJALANKAN DI KOMPUTER
1. Ekstrak file dimas-portfolio.zip.
2. Pastikan index.html dan style.css berada di folder yang sama.
3. Buka index.html dengan Google Chrome atau browser lain.

SEBELUM DIPUBLISH
1. Buka index.html.
2. Cari tulisan emailkamu@gmail.com.
3. Ganti semua kemunculannya dengan alamat Gmail yang ingin ditampilkan.
4. Jika ingin memakai foto, simpan foto dengan nama foto.jpg di folder yang sama.
5. Pada bagian hero di index.html, ganti <span>DF</span> dengan:
   <img src="foto.jpg" alt="Foto Dimas Dwi Fernanda">
6. Simpan perubahan dan cek ulang website.

PUBLISH DENGAN NETLIFY DROP
1. Buka https://app.netlify.com/drop melalui browser.
2. Masuk atau buat akun Netlify agar website mudah dikelola.
3. Seret folder dimas-portfolio ke area unggah (Drop zone).
4. Setelah proses selesai, Netlify akan memberikan alamat website yang berakhiran netlify.app.
5. Buka alamat tersebut untuk memeriksa website, lalu bagikan tautannya.

CATATAN
- Jangan ubah nama index.html.
- Pastikan style.css tetap berada satu folder dengan index.html.
- Jika memperbarui website setelah dipublish, unggah kembali folder yang sudah diperbarui melalui halaman deploy website di Netlify.
- Website ini bersifat publik setelah dipublish. Hindari menampilkan alamat rumah, nomor identitas, atau informasi pribadi yang sensitif.


MENAMBAHKAN FOTO PROFIL
1. Siapkan foto pribadi dalam format JPG, PNG, atau WebP.
2. Salin foto ke folder yang sama dengan index.html dan style.css.
3. Beri nama file foto-dimas.jpg.
4. Buka index.html di browser. Foto akan muncul di bagian utama dan Tentang Saya.
5. Jika nama atau format foto berbeda, ubah nilai src="foto-dimas.jpg" pada kedua tag img di index.html.

FILE WEBSITE
- index.html: struktur dan isi website.
- style.css: warna, tata letak, animasi, dan tampilan responsif.
- foto-dimas.jpg: foto pribadi yang kamu tambahkan sendiri.
